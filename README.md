# International Church of Pretoria — Website

The web home of the **International Church of Pretoria (ICP)** — a family of believers established in Pretoria on 21 November 1993. The site lives at **[icpretoria.org](https://icpretoria.org/)**.

This repository holds the source for a single-page React application: an editorial home page, a department directory, a multi-chapter photo archive, and a real 404. It speaks English and French, follows the dark/light system theme, quietly shifts its accent colours by liturgical season, and reminds visitors when the next Sunday gathering is.

> "A welcoming spiritual home for all who call on the name of Jesus."

## Quick start

```bash
# 1. Install dependencies (Node 18+ recommended)
npm install

# 2. Copy the env template and fill in real values when ready
cp .env.example .env

# 3. Run the dev server
npm run dev
```

The site will be live at `http://localhost:5173` with hot reload. Edit any file under `src/` and the page refreshes.

### Available scripts

| Command | What it does |
|---|---|
| `npm run dev` | Vite dev server with hot module replacement |
| `npm run og` | Regenerate `public/og-image.jpg` + `.png` from the SVG source |
| `npm run build` | Production build (runs `og` first, then `vite build`) |
| `npm run preview` | Serve the production build locally to sanity-check it |

## What's inside

The site is composed of three routes:

### `/` — Home
A single long scroll, structured as a journey:

1. **Hero** with a rotating 4-image carousel, a live countdown to next Sunday service (Africa/Johannesburg time), and a typewriter-style word animation.
2. **Ticker** of weekly rhythms.
3. **About** with a 30-year anniversary badge that animates on scroll.
4. **Stats** — a count-up band (years, departments, sermons, photos).
5. **Announcement** — weekly gatherings + cell groups.
6. **Sermons** — three latest, pulling live thumbnails from YouTube.
7. **Events** — annual recurring services (Women's Day, Christmas, NYE) with dates auto-computed each year.
8. **Gallery preview** — bento + collection deep-links.
9. **Scripture of the year**.
10. **Map** with offline fallback + contact strip.

### `/departments`
A grid of every ministry team, each with icon, description, and meeting schedule. Closes with a unified "take the next step" band.

### `/gallery`
A two-act page:
- **Memory Lane** — a sepia, vintage-treated slideshow of the church's earliest photos (`Old-Images/`).
- **Present-day archive** — chapters per ministry collection, sourced from `Gallery-Page-Images/<Category>/`. Includes a jump-nav, photo lightbox, video tile, and unified warmth + vignette across all imagery.

### `*` (anything else) → `NotFound`
A designed 404 with quick links home and to Plan-Your-Visit.

## Editing content

Most of what visitors read lives in one place: **`src/i18n/translations.js`**. Section by section, English first then French. Update the strings, save, the page reloads. See [`docs/CONTENT_GUIDE.md`](./docs/CONTENT_GUIDE.md) for a walkthrough for non-developers.

A few things live outside translations:

- **Gallery photos** — drop image files into `src/assets/images/Gallery-Page-Images/<Category>/`. Subfolders define collections. The page picks them up automatically.
- **Home bento** — same idea but in `Home-Gallery-Images/`. Filenames double as captions (`A-Joyful-Noise.jpg` → "A JOYFUL NOISE").
- **Memory Lane** — drop early-era photos into `Old-Images/`. The sepia treatment is applied at render time.
- **Sermons** — `SERMON_REFS` in translations.js. Update the `youtubeId` of each entry; titles and thumbnails are pulled live from YouTube via oEmbed.

## Theming

The site supports three layered modes:

1. **Light / Dark** — controlled by the toggle in the nav. Persists in `localStorage`.
2. **Liturgical season** — auto-detected from the calendar (Advent, Christmas, Epiphany, Lent, Easter, Pentecost, Ordinary Time). Subtly shifts the cyan/gold accents — the brand identity stays intact. Override via `localStorage.icp-season-override`.
3. **Photo warmth** — gallery imagery gets a unified `brightness + saturate + sepia` filter via the `photo-warmth` mixin so wildly different camera sources feel like one voice.

Palette tokens live in `src/styles/_variables.scss`. Edit them once; every section follows.

## Internationalisation (i18n)

Two languages out of the box:

- **English** — the primary
- **French** — full parity (most of the church speaks French as a first language, given the Pan-African roots)

To add a third (e.g. Portuguese for Lusophone members):

1. In `src/i18n/translations.js`, copy the `en` block and translate it.
2. Add the language to `LanguageContext` (`src/context/LanguageContext.jsx`).
3. Update the `nav__lang` toggle if you want a three-way switch instead of a two-way.

## Browser support

Latest two versions of Chrome, Edge, Firefox, Safari. iOS Safari 14+ and Chrome on Android. The site degrades gracefully on older browsers (no `IntersectionObserver` → eager mounting, no `backdrop-filter` → solid backgrounds, no JS at all → the `<noscript>` block surfaces the church's address and service time).

## Tech choices, briefly

- **Vite over CRA / Next** — pure SPA, no SSR needed, ship time matters. Vite's HMR and build speed are unmatched for a project this size.
- **SCSS over Tailwind / Styled Components** — the design has strong typographic identity (Cormorant Garamond + Cinzel) and reusable mixins handled this better than utility classes. Tokens live in CSS custom properties so theme switching is instant.
- **React Router 7** — modern API, lazy routes, hash-based deep-linking into the gallery.
- **No CMS yet** — for a v1 site with a single editor, `translations.js` is fast and free. CMS planned for when multiple non-devs need to edit weekly.
